# Метроном для Android

Точный метроном на Kotlin и Jetpack Compose. Три звука синтезируются локально,
четвёртый — сэмпл реального механического метронома (CC0).

## Возможности

- **Темп 30–300 BPM**: большие цифры (тап по ним = TAP-tempo с усреднением
  до 5 последних интервалов и вспышкой), кнопки −5/+5 по бокам, слайдер
  точной настройки.
- **Ударов в такте 1–8**: первый удар такта звучит выше и громче.
- **Четыре звука**: «Дерево» (~850 Гц), «Тик» (~700 Гц), «Импульс»
  (~1450 Гц) — синтезируются на устройстве (`ClickSynthesizer`); «Механика» —
  запись щелчка настоящего механического метронома (Wikimedia Commons,
  CC0, вырезан один удар).
- Настройки (темп, удары в такте, звук) сохраняются локально.

## Тайминг

Доли планируются заранее от абсолютного номера сэмпла с начала
воспроизведения — кумулятивного дрейфа нет. Смена темпа, размера, цикла и
звука применяется на лету, без остановки и щелчков. Срабатывание звонка или
вынимание наушников корректно останавливает воспроизведение
(аудио-фокус + `ACTION_AUDIO_BECOMING_NOISY`). Фоновое воспроизведение
намеренно не поддерживается.

Подробности — в [docs/METRONOME_NOTES.md](docs/METRONOME_NOTES.md).

## Сборка

Требуются Android SDK и Gradle. minSdk 24, target/compile SDK 35, Java 17.

```bash
gradle clean test assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

## Архитектура

- `core/` — чистый Kotlin: `TempoMath`, `BeatPlacer`, `TapAverager`.
- `audio/` — `ClickSynthesizer` и `ClickMixer` (чистые), `SampleClicks`
  (загрузка сэмпла «Механика»), `MetronomePlayer` (интерфейс),
  `AudioTrackMetronomePlayer` (единственный Android-зависимый класс движка).
- `state/` — `MetronomeViewModel`: плеер и tapper инъектируются фабриками и
  тестируются на фейках.
- `settings/` — `Prefs` (интерфейс) + реализация на SharedPreferences.
- `ui/` — Compose-экран на Material 3.

56 unit-тестов покрывают математику темпа, размеры, расстановку долей,
tap-tempo и переходы состояний ViewModel.
